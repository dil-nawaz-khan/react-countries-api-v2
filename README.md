# React Countries API App

## Project Overview

A modern React application that displays country information from a REST API, featuring a clean UI with dark/light theme support and responsive design.

## Live Demo

🌐 [React Countries App](https://react-js-countries-list-app.netlify.app/)

## GitHub Repository

📦 [Source Code](https://github.com/engineer-dilnawaz/react-countries-api-v2)

## Key Features

- Country information display
- Dark/Light theme toggle
- Responsive design
- React Router for navigation
- Context API for theme management

## Tech Stack

- React 18.2.0
- React Router DOM 6.10.0
- Parcel Bundler 2.8.3
- Context API for state management

## Project Structure

- Components-based architecture
- Context-based theme management
- Modular CSS styling
- Clean and maintainable code structure

## Development

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## Deployment

- Deployed on Netlify
- Continuous Deployment from GitHub repository
